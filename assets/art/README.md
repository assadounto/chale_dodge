# Chale, Dodge! production art

These original bitmap assets were created with the built-in image-generation tool using the Chale, Dodge! concept board as the visual reference. The runtime versions are resized/encoded for mobile and bundled for offline use.

- `hero-classic.png`: full-body original Ghanaian cartoon hero, curly black hair, yellow shirt, blue shorts, white sneakers, energetic dodging pose, rich cel shading, transparent background.
- `hero-teal.png`: the same original hero in mint teal shirt and deep teal shorts, transparent background.
- `hero-purple.png`: the same original hero in lavender shirt and violet shorts, transparent background.
- `reaction-shock.png`: shocked bust portrait of the hero holding his head, exaggerated eyes and open mouth, transparent background.
- `home-lane.jpg`: sunny Ghanaian neighbourhood lane, turquoise/coral houses, banana leaves, laundry lines, sandy orange ground, blue sky, clear centre for interactive overlays.

Prompt direction shared across the set: match the concept board's premium hand-painted 2D cartoon treatment, bold navy outlines, dimensional cel shading, warm highlights, saturated colours; no celebrities, third-party logos, UI labels, or embedded text.

The title is a vector design made from the bundled Luckiest Guy font. Button faces, reaction bursts, HUD, and all controls are live UI, not a flattened screenshot. The gameplay courtyard remains a separate overhead background so movement and collision coordinates stay consistent.
